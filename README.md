# NetPlixx

🎬 NetPlixx is a simple streaming web app inspired by Apple TV, built with React and Vite.

Browse movies, TV shows, anime, trailers, and more in one place.

## Tech

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- HLS.js

## Run locally

```bash
git clone https://github.com/prasadm11/Netplixx.git
cd Netplixx
npm install
npm run dev
```
